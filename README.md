# Cursor Onboarding Guide - Wizard-of-Oz Prototype

An interactive proof-of-concept onboarding experience for Cursor AI IDE, simulating AI-powered development workflows through a wizard-of-oz approach.

## 🎯 Overview

This prototype demonstrates how new users can experience Cursor's AI coding capabilities through:
- **AI Magic Moment**: Watch AI generate production-ready code in seconds
- **Hands-On Practice**: Interactive chat with simulated AI assistance
- **Feature Discovery**: Learn essential Cursor shortcuts and features
- **Confidence Building**: Apply learned skills to solve real coding challenges

## 🚀 Live Demo

Visit the live demo: [Cursor Onboarding Guide](https://lpcode808.github.io/Cursor-Onboarding-mockup/)

## 💻 Local Development

### Prerequisites
- Node.js 20+
- npm

### Setup

```bash
cd cursor-onboarding
npm install
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```
